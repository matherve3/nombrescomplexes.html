🔹 1. Forme algébrique & Module ▶

Définition : Un nombre complexe $z = a + ib$ avec $a,b\in\mathbb{R}$ et $i^2 = -1$.

$\Re(z) = a$ (partie réelle), $\Im(z) = b$ (partie imaginaire).

Conjugué : $\overline{z} = a - ib$.

📌 Module

$|z| = \sqrt{a^2 + b^2}$. Interprétation géométrique : distance $OM$.

Propriétés : $|z|^2 = z\overline{z}$, $|zz'| = |z||z'|$, $\left|\frac{z}{z'}\right| = \frac{|z|}{|z'|}$ ($z'\neq0$).

Inégalité triangulaire : $|z+z'| \le |z| + |z'|$.

🔹 2. Forme trigonométrique & exponentielle ▶

Forme trigonométrique : $z = r(\cos\theta + i\sin\theta)$ avec $r = |z|$ et $\theta = \arg(z)$ $[2\pi]$.

📌 Formule d'Euler

$e^{i\theta} = \cos\theta + i\sin\theta$

Forme exponentielle : $z = r e^{i\theta}$.

Formule de Moivre : $(e^{i\theta})^n = e^{in\theta}$, donc $(\cos\theta+i\sin\theta)^n = \cos(n\theta)+i\sin(n\theta)$.

⚡ Arguments

$\arg(zz') = \arg(z) + \arg(z')$ $[2\pi]$.
$\arg\left(\frac{z}{z'}\right) = \arg(z) - \arg(z')$ $[2\pi]$.
$\arg(\overline{z}) = -\arg(z)$ $[2\pi]$.

🔹 3. Équations dans $\mathbb{C}$ ▶

Équation du second degré : $az^2 + bz + c = 0$ ($a\neq0$).

$\Delta = b^2 - 4ac$. Si $\Delta < 0$, deux solutions complexes conjuguées : $z = \frac{-b \pm i\sqrt{-\Delta}}{2a}$.

📌 Racines $n$-ièmes de l'unité

Les solutions de $z^n = 1$ sont les $n$ nombres complexes : $e^{2ik\pi/n}$, $k = 0,1,\dots,n-1$.

Exemple : racines cubiques $1, j, j^2$ avec $j = e^{2i\pi/3}$, et $1+j+j^2 = 0$.

🔹 4. Géométrie du plan complexe ▶

Affixe d'un vecteur : $\overrightarrow{AB}$ a pour affixe $z_B - z_A$.

Distance : $AB = |z_B - z_A|$.

Milieu : $I$ milieu de $[AB]$ a pour affixe $\frac{z_A+z_B}{2}$.

📐 Transformations du plan

Translation de vecteur $\vec{u}(b)$ : $z' = z + b$
Rotation de centre $O$ et d'angle $\theta$ : $z' = e^{i\theta}z$
Homothétie de rapport $k$ : $z' = kz$
Similitude directe : $z' = az + b$ ($a\in\mathbb{C}^*$, rapport $|a|$, angle $\arg(a)$)
